Why a Separate Showcase?

The Back-Office Suite targets enterprise operations (Austrian ebInterface, SEPA, AZG 38.5h, ROI). The DIY Craft Fleet shares the same Rust ArtCraft harness, but serves makers, creators, researchers, and engineers.

Layer 1 • Core

Pure-Rust Domain Engine

In-process state machines, SQLite/file stores, DSP, geometry, or kinematics with strict clippy lints and zero network/cloud lock-in.

Layer 2 • CLI & MCP

Scriptable & Agent-Ready

Every action exposed over a unified Command dispatch bus — runnable from the terminal or by AI agents over MCP stdio.

Layer 3 • egui Studio

Native Desktop Speed

Immediate-mode egui / wgpu interfaces with sub-second startup and a fraction of Electron's memory footprint.
