# Changelog

All notable changes to `craft-showcase` will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [0.1.0] - 2026-11-10

### Added
- Pure-Rust `eframe 0.37` WebAssembly interactive studio (`craft-showcase-wasm`) compiled with `trunk`.
- Multi-app browser tabs for `HelmCraft`, `BillCraft`, `SpendCraft`, `HireCraft`, and `TaskCraft`.
- Responsive client landing page (`web/index.html`) with dark-mode aesthetic and Tailwind typography.
- Interactive SaaS vs. Sovereign Suite ROI calculator with dynamic seat slider.
- Autonomous domino event cascade interactive diagram.
- 2.5-minute video presentation script and storyboard for executive demos.
- Central fleet launcher `mcp-central-docs\starts\craft-showcase-start.bat` with `--smoke` verification.
